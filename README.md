# nassauTickets_

Sistema de controle de atendimento para um Laboratório de Análises Clínicas, desenvolvido com organização de projeto, controle de versão no Git/GitHub, documentação técnica e frontend em React[cite: 1, 7, 8].

## Objetivo
Gerenciar a emissão, priorização, chamada, atendimento, auditoria e emissão de relatórios de senhas (SP, SG e SE) entre os agentes AS, AA e AC[cite: 1, 3, 4, 5].

## Tecnologias Utilizadas
- **Frontend:** React
- **Backend:** Node.js
- **Banco de Dados:** MySQL 8.0

## Arquitetura e Visão Geral
O projeto é dividido em `frontend/`, `backend/` e `docs/`, integrando o totem do cliente (AC), o terminal do atendente/gestor (AA), o painel de chamadas e a lógica do sistema (AS) com persistência no banco de dados[cite: 2, 3, 6, 8].
